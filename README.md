# Green-API Chat UI (Тестовое задание)

Минималистичный пользовательский интерфейс чата для отправки и получения текстовых сообщений через GREEN-API (MAX/WhatsApp). Проект выполнен в рамках тестового задания для Frontend-разработчика.

## Стек технологий

- **React 18+** (функциональные компоненты, хуки)
- **TypeScript** (строгая типизация)
- **Vite** (сборка и локальный сервер)
- **CSS / Tailwind CSS** (минималистичный дизайн в стиле web.max.ru)
- **ESLint + Prettier** (контроль качества кода и форматирование)
   Замена на
   **Biome** - (линтер и форматтер, выбран вместо ESLint/Prettier для скорости и современности)
- **Docker** + **Dev Container** (готовое окружение для разработки)

## Реализованный функционал

- [x] Отправка текстовых сообщений через API GREEN-API.
- [x] Получение и отображение входящих сообщений в реальном времени (Webhook / Polling).
- [x] Минималистичный UI, повторяющий стилистику web.max.ru.
- [x] Отсутствие предупреждений при линтинге (ESLint/Prettier).
